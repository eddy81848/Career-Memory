## 3. Existing `schemas/case.schema.json` Limitations (Schema Gaps)

Existing `schemas/case.schema.json` (`event-draft-case.v1`) sets `additionalProperties: false` throughout, so the following confirmed concepts cannot be expressed in `case.schema.json` without an owner-approved schema bump (isolated here in [`schemas/delta-candidate.schema.json`](schemas/delta-candidate.schema.json); no product API or shared schema edits made):

1. **`SCHEMA_GAP_DIRECT_COMMIT_CONFIRMATION_EXPECTATION`**: `expected_proposal.events[*]` lacks a direct-commit user association-confirmation-needed semantic field (`review_flags` only models `mixed_purpose_hint_present` for `EV-007`).
2. **`SCHEMA_GAP_SYNC_IMPORT_WINDOW_AND_PR_MERGE_STRATEGY`**: `repositories[*]`, `sync_runs[*]`, `pull_requests[*]`, and `commits[*]` lack `default_branch_reported_by_provider`, `import_window_start`/`end`, `merge_strategy`, `within_import_window`, `heuristic_similarity_decoy_for_pr_id`, separated `synthetic_sources.out_of_window_pr_associations` (fixture input premise distinguishing merge-time head SHA from import-time provider observation), and semantic `expected_proposal.out_of_window_pr_dedup_checks` (without prescribing internal diagnostic persistence).
3. **`SCHEMA_GAP_EVENT_RELATIONS_AND_CANNOT_LINK_CATEGORY`**: `synthetic_sources` lacks logical `event_relations` (`CANNOT_LINK` between active Events); `command_results[*].rejection_category` lacks `"cannot_link_conflict"` (even though `spec_error_code` already allows `"CANNOT_LINK_CONFLICT"`).
4. **`SCHEMA_GAP_CONFIRM_EDIT_COMMANDS_AND_REVIEW_ACTION`**: `user_commands[*].command_action` lacks `confirm`/`edit` and `spec_command_name` only allows `"UNCONFIRMED"` (cannot record confirmed `MVP API §5` routes `POST /work-events/{id}/actions/confirm` and `PATCH /work-events/{id}`); `initial_events[*]`/`events[*]` lack curated `title`/`summary` and `previous_version`/`prior_version_preserved`; `expected_proposal` lacks `review_actions` separating `DB Model` domain `ReviewAction` (`CONFIRM`/`EDIT`) from unconfirmed external API response tokens.
